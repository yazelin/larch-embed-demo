Larch：最直覺好用的視覺小說製作工具

把故事創作變簡單：在無限白板上自由編輯劇本與分支，在任意卡片上直接播放效果，然後一鍵發佈成可以分享的網頁遊戲，或匯出 Unity 擴充功能、Godot 專案、Windows 與 Mac 執行檔、Android 與 iOS App，以及純 JSON。

不用寫程式。場景、對話、選項、變數與跳轉都是白板上的卡片，拉一條線，分支就成立了。視覺小說、AVG 文字冒險、互動小說與 RPG（地圖、事件、戰鬥）都能做。

直覺、簡單，第一次打開就會用

  • 一張白板，整個故事

    每張卡片是一個畫面，拉一條線就是劇情的下一步，也就是一個分支。卡片隨手拖、隨手排，一個專案可以有很多張白板。

  • 一張卡片，就是一個畫面

    點開卡片，照著 1、2、3 選角色、挑表情、寫台詞，左邊的舞台馬上變成遊戲裡的樣子。背景、音樂、特效和變數，都收在同一張卡片裡。

  • 寫到哪，就玩到哪

    任何一張卡片都能按下播放，立繪、背景、音樂和選項都真的跑起來。節奏不對、台詞太長，當下就看得出來，也當下就能改。

  • AI 幫你寫，也幫你畫

    在角色工坊用一句話生成立繪、一鍵去背，台詞按一下就有 AI 配音；也能貼上劇本讓 AI 整理成卡片，或一次翻譯整份專案。

一款視覺小說需要的東西，都在同一份專案裡

  • 直覺的白板

    場景、對話、條件分支、變數、玩家輸入、小遊戲與多張分鏡板。卡片可以複製、分組、跨板搬移。

  • 角色工坊

    個性、來歷、表情組、透明立繪與聲線寫一次，就會被帶進預覽、AI 回覆與匯出成品。

  • 素材市集

    上傳自己的素材，或從市集下載 BGM、場景背景、道具等各種內容，直接加入專案使用。

  • AI 深度整合

    AI 可以起草劇情、以角色身分即興回話、生成立繪與表情、一鍵去背、翻譯整份專案。需要時才開，手動創作永遠免費。

  • Unity 擴充功能

    匯入一次，故事就變成 ScriptableObject，附帶 C# Runtime、Editor 故事圖、存檔槽與可播放的範例場景。

  • MCP 與開放 API

    Larch 開了 MCP Server 與 REST 介面，Claude Code、Codex 這類 agent 可以直接讀寫故事、建立角色、生成美術。

常見問題

  • 需要會寫程式嗎？

    不用。故事是白板上的卡片，分支是拉出來的線。只有在你想把成品接進 Unity 或自己的服務時，才會碰到程式，而那部分我們提供現成的 Runtime 與 API。

  • 免費版可以做到什麼程度？

    無限專案、每個專案 100 張卡片，角色、媒體、預覽、Unity 同步與 API Key 都能用，另有每月 20 枚松果幣可以試用 AI 功能。

  • 一定要用 AI 嗎？

    完全不用。所有 AI 功能都是選用的，手動創作永遠免費，也不會有任何內容被強制送去生成。

  • 作品是我的嗎？可以帶走嗎？

    是你的。專案隨時可以匯出成乾淨的 JSON，那份資料就是完整的故事來源，不需要 Larch 也能繼續使用。

  • 官方素材可以商用嗎？

    Larch 第一方官方素材包可免費用於任何平台的商業或非商業成品與宣傳，但不得拆售或重新分發原始檔。第三方示例素材則依各自原廠條款；每個素材在商城裡都標示了授權。

Larch 是免寫程式的視覺小說與 AVG 文字冒險遊戲製作工具：分支劇情白板、角色表情、AI 配音與翻譯、Live2D 與 Spine，一鍵發佈網頁遊戲，或匯出 Unity、Godot、Windows、Mac 與手機 App。也能做 RPG 遊戲。
